EXPERIMENT#1

LED BLINK

CONCEPT
Digital Output Control
COMPONENTS
Arduino Uno Board
1x Red LED (5mm)
1x 220Ω Resistor
Breadboard & Jumpers
LEARNING
•pinMode() pin direction setup
•digitalWrite() HIGH / LOW states
•delay() millisecond pause
ARDUINO C++ CODE SKETCH
// Experiment 1: LED Blink
const int LED_PIN = 13;

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_PIN, HIGH);
  delay(1000);
  digitalWrite(LED_PIN, LOW);
  delay(1000);
}
EXPLANATION
The setup() function initializes digital pin 13 as an OUTPUT pin. In loop(), digitalWrite(13, HIGH) applies 5V to light up the LED. After 1000ms, digitalWrite(13, LOW) turns off the voltage. This loop repeats infinitely.
WORKING PRINCIPLE

When digital pin 13 outputs HIGH (5V), current flows through the 220Ω resistor, through the LED anode to cathode, and into GND, making the LED illuminate. Setting pin 13 LOW stops current flow.

EXPECTED RESULT

The LED blinks ON and OFF repeatedly at 1-second intervals.

ENGINEER'S TIP

Always connect a 220Ω resistor in series with an LED to prevent excessive current from damaging the LED or Arduino GPIO pin!

Professional Code of Ethics & IEEE STEM Safety Standards

1. Hardware & Component Stewardship

Always verify supply voltage polarity and insert 220Ω current-limiting resistors before applying power to prevent semiconductor breakdown and electronic waste.

2. Code Integrity & Fail-Safe Defaults

Write modular, non-blocking, thoroughly commented C++ sketches. Enforce default LOW fail-safe pin states for all motor and high-voltage actuator channels.

3. Responsible STEM Innovation

Design embedded hardware and IoT systems that prioritize user physical safety, environmental sustainability, open hardware documentation, and public benefit.
